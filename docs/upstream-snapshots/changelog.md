# Google Antigravity 2.0 Upstream Baseline Snapshot (`v2.21.1` → `v2.33.0`)

Synced Baseline: `2026-11-20` (App `v2.33.0`, CLI `v1.5.11`, Model Launch: Gemini 4 Neon & Orchestrator `2026-11-18`).

## Model Launches (Nov 2026)
- **Gemini 4 Neon** (Nov 18, 2026): Default reasoning model (512K context), 4 thinking levels (`Low`, `Medium`, `High`, `Extra`/`xhigh`), `Orchestrator (Neon)` planning with Neon + implementing with Hydrogen.
- **Gemini 4 Hydrogen** (Nov 12, 2026): Fast coding & agentic execution across 4 thinking levels, powers Orchestrator implementation phase.
- **Gemini 4 Carbon** (Nov 10, 2026): Strongest frontier model for long-horizon software engineering, knowledge work, scientific discovery, and cybersecurity (`Orchestrator (Carbon)`).
- **Gemini 4 Argon**: Frontier reasoning model (`Orchestrator (Argon)`).
- **Deprecation**: Claude 4.6 (Sonnet/Opus) and GPT-OSS-120b scheduled for removal Nov 30, 2026.

## Antigravity App Releases (`v2.21` → `v2.33.0`)
- **v2.33.0** (Nov 17, 2026): Connect over SSH (64-bit Linux remote server), live GitHub PR status pills & hover cards + Overview Pull Requests section, `/btw` Insert into main conversation, built-in browser Cmd/Ctrl+F, Nord theme, 200MB audio/video playback & `.amr` voice recordings, enterprise `admin_settings.json` policies.
- **v2.32.2** (Nov 16, 2026): Multi-turn `/btw` Side Question tabs with read-only workspace tool access.
- **v2.32.0** (Nov 13, 2026): Dynamic Workflows (`/run-workflow`) Python multi-agent orchestration (`parallel()`, `pipeline()`, JSON Schema outputs), Everforest Light/Dark themes, prompt navigation shortcuts, model selector Refresh button, cross-site browser frame isolation.
- **v2.31.0** (Nov 9, 2026): `/swarm` multi-agent message board coordination, interface font size (12/14/16px), split-view plugin panels, browser download approvals (`download_url`), voice call summary transcript cards, voice-driven multi-question advancement, unified Local/Remote Create Project wizard.
- **v2.30.0** (Nov 9, 2026): Knowledge Work vs Software Engineering interface layouts, Voice Mode & Remote Agents GA rollout, Built-in Browser Agent (parallel tabs, live cursor, pause-and-resume sign-in handoff, comment/quote), per-conversation permission preset in message box, `Auto` preset GA, import setup from Claude Code/Codex/Cursor.
- **v2.29.0–v2.29.1** (Nov 3–6, 2026): Voice Mode (Gemini Live two-way speech, 9 voices, 0.75x–2x speed), Remote Agents (GitHub/Drive/Uploaded files), redesigned Home & Automations, native Jupyter Notebook (`.ipynb`) viewer.
- **v2.28.0–v2.28.2** (Oct 27–29, 2026): Built-in side-panel browser, PDF viewer, any-file attachments, word/char diff highlighting, Conversation Navigator, Marketplace partner plugins (Figma, Linear, Notion, Stripe) & OAuth sign-in.
- **v2.21–v2.27** (Oct 2026): Message-box permissions picker (`Request Review`/`Default`/`Auto`/`Turbo`), `.zip` & folder attachments, fullscreen image/video viewer + image region commenting, MCP structured step headers + startup errors/Restart, Markdown YAML frontmatter summary, persistent sidebar collapsed folders.
