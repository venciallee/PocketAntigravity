# ESDD End-to-End Functional & UE Visual Acceptance Test Plan (v2.1 — Official v2.34 & Dual-Platform Aligned)

## 1. Verification Philosophy

Every requirement from the 13 core UE states (`UE01` .. `UE13`) and 7 extended UE boards (`UE01B`, `UE06B`, `UE06C`, `UE07B`, `UE08B`, `UE14`, `UE15`) is verified end-to-end across **4 automated gates** on both **iOS** and **Android**:

1. **Gate 1 — Mechanical Spec-DAG, Compatibility Guardrails & Contract Check**:
   - Validates all 13 canonical states (`UE01_AGENTS_HOME` .. `UE13_LIVE_ACTIVITY_SPEC`), 13 transitions (`E01` .. `E13`), 13 claims (`CLAIM-01` .. `CLAIM-13`), 7 extended screens, refined neutral Obsidian design tokens, 100% `data-testid` / `accessibilityIdentifier` / Compose `testTag` parity, pure-Swift `AntigravityData` isolation, and all 4 bidirectional compatibility guardrails.
2. **Gate 2 — Connect-RPC, Binary Protobuf & 3-Version Compat Matrix (`mock_language_server.py`)**:
   - Tests 5-byte Connect streaming frames (`JetboxSubscribeToSummaries`), 605-step binary `application/proto` trajectory decoding (`GetCascadeTrajectorySteps`), Face ID / Biometric-signed `HandleCascadeUserInteraction`, Project creation, Automation CRUD/Run/Pause/Resume, Customizations/Plugin toggle, Permission Presets, and Legacy (`v2.31`) / Current (`v2.33–v2.34`) / Future (`v2.99`) compatibility.
3. **Gate 3 — Interactive End-to-End User-Journey Tests (`TC-01` .. `TC-22`)**:
   - Executed across Headless ESDD (`verification/esdd-verify.py`), native iOS Simulator `XCUITest` (`tests/ios-ui/AntigravityInteractiveUITests.swift`), native Android Compose E2E (`AndroidInteractiveE2eTest.kt`), and KVM Android Emulator (`AndroidEmulatorE2eTest.kt`).
4. **Gate 4 — Strict 1:1 Side-by-Side Target UE vs Implemented Visual Comparison**:
   - Compares **LEFT: `docs/ue/ios/*.png`** vs **RIGHT: Real iOS Simulator SwiftUI renders** (`IOS_CMP_*.png`) AND **LEFT: `docs/ue/android/*.png`** vs **RIGHT: Real Android Jetpack Compose Roborazzi renders** (`ANDROID_CMP_*.png`), enforcing `overflowPx == 0` and minimum touch targets (`>=44pt` iOS / `>=48dp` Android).
